# 升级后清理

适用于 2026-10-22 重新编号的 1.0.0-rc.1 完整包。

## 升级成功后自动清理

按 INSTALLATION.md 的升级步骤操作。旧网站先使用包内新版 starlit.sh，再启动升级；这样本次升级就会执行自动清理。

网站与 HTTPS 检查通过、维护脚本更新完成后，无需确认，自动处理：

1. `/root/starlit-本次版本-source.tar.gz`。
2. 同名 `.sha256` 校验文件。
3. 本次 upgrade 命令指定的新解压 `starlit-本次版本-source` 目录。

上传文件与解压目录分别检查。目录必须在实际安装目录之外，与 `releases/本次版本/` 内部副本完全一致，没有额外文件、配置、数据、符号链接或挂载点。压缩包校验值和内部清单必须一致。

升级失败或检查不通过时保留相关对象并提示。清理失败不撤销已经完成的升级。

## 永远保留哪些内容

- 正在运行的网站安装目录。
- config/ 和 data/：账号、活动、数据库、上传图片、微信密钥、校验文件、证书。
- 本次升级前备份。
- releases/ 中的当前版本副本，供后续重建镜像使用。

首次安装不会自动删除安装目录。解压目录自动删除仅发生在升级成功后。

## 手动清理历史文件

历史版本、旧备份和镜像不定时自动删除。在原网站安装目录运行下面的命令，仅查看清单：

```bash
bash starlit.sh cleanup
```

确认后再运行：

```bash
bash starlit.sh cleanup --apply
```

输入 CLEAN 才会删除。保留当前版本、可识别的上一版本、最近两次完整备份及其依赖源码和镜像。无法确认归属、备份不完整、目录含额外文件时保留。其他容器使用的镜像保留；不执行全局 Docker prune。

首次安装后，如果要清理上传的压缩包和校验文件，可以先查看：

```bash
bash starlit.sh cleanup --downloads
```

确认后执行：

```bash
bash starlit.sh cleanup --downloads --apply
```

输入 CLEAN 后执行。该命令同时可能包含上述历史文件清单，请先阅读预览。
