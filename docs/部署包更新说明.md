# 星遇 1.0.0-rc.2 · 完整 Docker 镜像部署包

## 下载与安装

下载 Release 附件中的 starlit-1.0.0-rc.2-images.tar.gz、同名 .sha256 和 INSTALLATION.md，按说明书逐步操作。不要使用 GitHub 自动生成的 Source code 下载项进行服务器安装。

## 包含内容

- Linux amd64 应用镜像、Caddy 网关镜像、PostgreSQL 数据库镜像，统一保存在包内 images.tar。
- 自动安装 Docker Engine 和 Compose 的脚本、配置模板、数据库迁移及维护工具。
- 首次安装不要求用户先手动安装 Docker；自动创建配置并引导设置网站账号。
- 从旧源码包升级时保留账号、活动、名单、上传图片、微信配置、数据库和备份。
- 升级成功且检查通过后，删除本次上传到 /root 的镜像压缩包及校验文件，并删除本次新解压目录。
- 原网站目录、当前内部版本副本和备份保留。失败、文件变更或路径异常时不自动删除相关文件。
- 镜像已经导入时，后续启动不重复导入；镜像包损坏或缺失时明确报错，不悄悄转为源码构建。

## 运行要求

Ubuntu 22.04/24.04 或 Debian 12/13，x86_64 架构，root 权限。域名已解析，TCP 80/443 已开放。安装 Docker 需要访问系统和 Docker 软件源，HTTPS 及微信需要网络。本包省去应用镜像下载与现场编译，不是完全离线安装包。

## 验证

发布前执行 13 项源码与部署验收，并从导出的镜像归档启动真实容器，检查数据库迁移、账号初始化、API 健康、前端入口、微信校验文件访问和数据库重启后的数据保留。具体结果见 RELEASE.json。

真实公网 HTTPS 与手机微信授权仍需在实际服务器验证。本包不含开发电脑的业务数据或私密配置。
