# 星遇部署说明

适用安装包：**starlit-1.0.0-rc.1-source.tar.gz**（2026-10-22 重新编号的新版本，包含此前功能及最新自动清理）。

第一次安装和更新已有网站，都先完成第 1、2 部分。之后，首次安装看第 3 部分，升级看第 4 部分，二选一。

**每次只执行一个命令框。命令完成、没有报错后，再继续下一步；报错就停下。**

## 1. 上传文件

使用 FTP 工具上传，推荐 [FileZilla Client](https://filezilla-project.org/download.php?type=client)。

打开 FileZilla，点击「文件 → 站点管理器 → 新站点」，填写：

| 项目 | 填写内容 |
| --- | --- |
| 协议 | SFTP |
| 主机 | 你的服务器公网 IP |
| 端口 | 22；服务商另有指定时使用指定端口 |
| 登录类型 | 正常 |
| 用户 | root |
| 密码 | 你的服务器密码 |

点击「连接」。首次出现主机密钥提示时，核对服务商提供的指纹后确认。

连接成功后：

1. 在右侧「远程站点」栏输入 `/root/`，按回车。
2. 在左侧找到下面两个文件，依次拖到右侧。
3. 等待上传完成，确认底部没有失败的传输。

需要上传的文件：

- `starlit-1.0.0-rc.1-source.tar.gz`
- `starlit-1.0.0-rc.1-source.tar.gz.sha256`

保留原文件名，不需要在电脑上解压。

## 2. 在服务器上解压

登录购买服务器的网站，打开这台服务器的「远程连接 / 终端」，以 root 登录。

**以下命令都在服务器终端执行，不在 FileZilla 中执行。**

### ① 进入上传位置

```bash
cd /root
```

### ② 检查文件完整性

```bash
sha256sum -c starlit-1.0.0-rc.1-source.tar.gz.sha256
```

看到 **OK** 或「成功」才继续。

### ③ 创建默认安装位置

```bash
mkdir -p /opt/starlit
```

### ④ 解压

如果服务器已经存在 `/opt/starlit/starlit-1.0.0-rc.1-source`，先停止操作，不要覆盖；早期同名 rc.1 与本次重新编号版本不同。旧网站恰好使用 rc.1 或内部已保留 rc.1 副本时，需要单独安排迁移，不能直接套用本说明。

```bash
tar -xzf /root/starlit-1.0.0-rc.1-source.tar.gz -C /opt/starlit
```

等待命令结束。没有报错、重新出现命令提示符，就可以继续。

**现在选择：没有安装过，做第 3 部分；已经安装过，跳到第 4 部分。**

## 3. 首次安装

安装前需满足：Ubuntu 22.04 / 24.04 或 Debian 12 / 13，x86_64 架构；域名已解析到服务器公网 IP；TCP 80、443 端口已放行。Docker 和数据库由程序安装。

### ① 进入新包目录

```bash
cd /opt/starlit/starlit-1.0.0-rc.1-source
```

### ② 启动安装

```bash
bash install.sh
```

### ③ 按屏幕提示填写

| 提示 | 填什么 |
| --- | --- |
| 网站域名 | 你的网站域名，不带 https://、端口或路径 |
| 登录账号 | 自己设置的网站账号 |
| 设置密码 | 自己设置的网站密码 |
| 再次输入密码 | 再输入一次相同密码 |

每次填写后按回车。密码输入时不显示字符，是正常现象。

保持窗口开启，等待出现 **「网站已启动」**。然后在浏览器打开网站，用刚设置的账号和密码登录。

**首次安装完成，不需要再执行升级步骤。**

## 4. 升级已有网站

请避开活动进行期间。升级会自动备份，保留服务器上的账号、活动、名单、图片和配置。

### ① 进入原网站目录

下面的命令适用于按默认方式安装在 `/opt/starlit/` 下的单个网站，会自动定位原目录，星号不用修改：

```bash
cd /opt/starlit/*/config/..
```

**这一条没有报错，才能继续。**若提示找不到目录或参数过多，停止并提供报错截图，不要执行下一条。

### ② 更新原网站的维护脚本

这一步让本次升级立即具备自动清理功能，不需要另下载补丁。

先保留原脚本：

```bash
cp -p starlit.sh starlit.sh.before-upgrade
```

再使用新包中的脚本：

```bash
install -m0700 /opt/starlit/starlit-1.0.0-rc.1-source/starlit.sh ./starlit.sh
```

### ③ 启动升级

```bash
bash starlit.sh upgrade /opt/starlit/starlit-1.0.0-rc.1-source
```

保持窗口开启，等待出现 **「升级完成」**。通过清理检查后，会自动删除 `/root/` 下本次上传的压缩包及校验文件，以及本次新解压目录；原网站目录、配置、业务数据、备份及内部版本副本保留。升级失败或检查不通过时保留相关文件。

不要执行 `install.sh`，不要删除原网站文件夹。

### ④ 刷新页面

- 电脑后台按 **Ctrl + F5** 刷新。
- 关闭旧大屏，再重新打开。
- 微信关闭旧签到页面，重新扫码。

升级完成。

## 出现报错怎么办

停在报错的那一步，保留窗口，将报错截图发来。不要删除文件或重新安装。
